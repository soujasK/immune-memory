## Requirements and manual checks

- Use the [Guidelines template](https://docs.google.com/document/d/1_1_27EyZriMlc8n8EBE2YScaeyMjm-8xjR097nmHXAE/copy?usp=sharing), verified via Google Docs export, v0.9.0. Submit PDF ≤25 MB, body ≤8 pages excluding references and appendices, abstract 150–250 words, author names and affiliations, and the required Limitations and Dual-Use / Ethical Considerations appendix. Template also requests an LLM usage statement. Remove all guidance.
- Submit through the sprint page form. Required fields include project title, short abstract, PDF, publication interest, team name, location, and name and email for each team member. Tracks, code, recording, slides, image, additional material, Discord and Scholar are available. Public code and 3–5 minute demo are optional. Verify confirmation email and PDF. Same-title resubmission before cutoff replaces the previous one.
- Solo and global participation allowed. Up to five members recommended, larger groups allowed per Guidelines and FAQ. Each entrant may join up to two projects. Declare preexisting work in README and report. Judging focuses on weekend work. AI tools are permitted with responsibility for accuracy. Incomplete work is permitted.
- Confirm authors approve the [submission and prize terms](https://apartresearch.com/sprints/prize-terms). Apart receives a nonexclusive license covering judging, processing and sharing. Prize terms cover equal team splits, transfer eligibility, forms and banking.
- Check title, author fields, abstract length, reference URLs, scope claims, PDF legibility, test results, figure provenance, oracle separation, and absence of secrets. Submit manually with team consent.
